index.html  - the portal page (host on GitHub Pages, Netlify, or any web host)
Code.gs     - Google Apps Script backend (paste into Extensions > Apps Script of your Google Sheet)

Setup:
1. Create a Google Sheet, open Extensions > Apps Script, paste Code.gs, save.
2. Deploy > New deployment > Web app. Execute as: Me. Who has access: Anyone.
3. Copy the Web App URL and paste it into SCRIPT_URL near the bottom of index.html.
4. Upload index.html to your host.
